# ASu 同款简历重制说明

## 本次版本

本版本按 ASu 单栏高密度技术简历模板制作，保留蓝色分区标题、浅灰经历条、紧凑项目标题、右上角证件照上传位和浏览器可编辑工具栏。与旧版相比，版式更接近 ASu 示例的“身份定位 - 最强证据 - 项目 - 技能”阅读顺序。

## 内容策略

- 顶部直接标注 Agent 开发 / 大模型应用开发方向，并把 Dify 已合并 PR 作为首屏证据。
- 项目只保留与目标岗位最相关的 RAG 私有化问答、语音硬件联动和 AI Coding OA 实践。
- 所有项目名称、时间、指标和个人边界沿用已确认的原始简历事实，不新增公司、论文或商业上线经历。
- 右上角证件照只保留可编辑上传位，没有把未提供的照片或虚构头像写进投递 PDF。

## 文件结构

- `resume/王鑫恩-阿酥同款-Agent大模型应用开发-简历.html`：ASu 公共资源内联后的可编辑 HTML。
- `resume/王鑫恩-阿酥同款-Agent大模型应用开发-简历.pdf`：A4 投递版 PDF。
- `resume/王鑫恩-阿酥同款-Agent大模型应用开发-简历.source.html`：内容源壳，便于后续继续生成。
- `resume/icons/`、`resume/logos/`：HTML 所需的本地图标资源。

## QA 记录

- PDF 目标为 A4 单页；完成导出后检查页数、纸张尺寸、工具栏隐藏、文本可复制和项目分区。
- 中文姓名、邮箱、GitHub 地址、Dify PR / Issue 链接和项目指标均保持可读；公开链接可直接点击，不使用整页截图替代文本。
- 证件照位在屏幕编辑时可点击上传，打印时自动隐藏占位提示；当前 PDF 不包含照片。
